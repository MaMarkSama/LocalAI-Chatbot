# Product Context — Gemma AI (Local Multi-user Intelligence Workspace)

## 1. Product Overview
- **Product Name:** Gemma AI — Local Multi-user Chatbot & Document Intelligence Workspace
- **Category:** Enterprise Internal AI Workspace / Local-first RAG & Web Research Platform (Mode: **Operate** & **Read**)
- **Stack:** FastAPI (Python), SQLite WAL + FTS5, Ollama Local LLM Runtime, Vanilla HTML5/CSS3/JS with GSAP motion & 3-tier CSS Design Tokens
- **Languages:** Bilingual Thai / English (`TH` primary UI, `EN` technical terms & code)

## 2. Target Audience & Use Scene
- **Primary Users:** Internal enterprise teams, analysts, engineers, and operations leads working with confidential documents and bilingual Thai/English workflows.
- **Usage Scene:** Multi-hour desktop and tablet sessions in variable office lighting, plus mobile on-the-go checks.
- **Core Jobs-to-be-Done:**
  1. Converse with local Ollama models (`gemma3`, `llama`, `qwen`) without sending sensitive data to external clouds.
  2. Upload and interrogate complex documents (PDF, DOCX, XLSX, CSV, XML, Code, Images) via semantic vector RAG (`MessageTurboVec`).
  3. Run cited, multi-query web research with numbered inline references (`[1]`, `[2]`).
  4. Organize conversations and files by project workspaces and export reports to Markdown.
  5. Monitor token throughput, model mix, search performance, user roles, and security audit trails in the `/admin` Command Center.

## 3. Brand & Voice
- **Persona:** Calm, authoritative, precise, and trustworthy local intelligence.
- **Copy Principles:** Clear Thai phrasing without awkward machine translation; controls state their exact action; error messages explain what happened and how to recover.
